01

Information we use

Depending on how you use QuaptureIQ, we may process:

  • the email address associated with your QuaptureIQ account;
  • an authenticated user ID used to identify your account securely;
  • photos and other images that you upload for a requested answer;
  • feedback you send through “Help us improve QuaptureIQ”;
  • account, usage, and entitlement data needed to operate the service.
02

How information is used

We use this information for app functionality and account management. Uploaded images and related request data may be processed by our backend as needed to provide answers and return the requested result.

Data is transmitted over HTTPS encryption in transit. QuaptureIQ does not sell your data or use it for advertising.

03

Service providers and public participation

To deliver QuaptureIQ, we use service providers for account authentication and storage (including Supabase), cloud backend hosting (currently Oracle Cloud), and model processing through our server-side routing services. When you request an answer, the uploaded image, relevant question text, and necessary processing context may be sent to the model services used to generate that answer. If you choose Google sign-in, Google also processes authentication information. Service providers may process data in countries other than your own. We do not sell your account information or learner content.

The optional Top Thinkers leaderboard displays only a participating user’s chosen nickname, ranking and points. Participation is opt-in and can be turned off in the app. We do not display private account email addresses or account identifiers on the public leaderboard.

04

Closed-test product analytics

During an approved closed test, when product analytics is enabled, QuaptureIQ collects only aggregate, content-free usage events: selected mode (Question, Source Analysis, Diagram Labels, or Locate), plan tier when returned by the authoritative wallet, selected voice (Quapture Voice or Sky), input path (choose a photo, take a photo, or scan a document), entry route (Q Lens from Home or Dashboard), sign-in method category (email or Google), answer requested/succeeded/failed, answer-next usage where the workflow can identify it, answer duration, and a normalized failure stage.

Product analytics does not collect prompts, answers, academic or source content, image bytes, OCR text, email addresses, authentication user IDs, stable device identifiers, credentials, or raw exception text. A random request-correlation value may associate events from one answer lifecycle, but it is not a stable user identifier and is not included in owner dashboard aggregates.

When active-session counting is enabled, the app sends a random temporary session code while it is in the foreground. The API keeps this code in memory only and forgets it within two minutes of its last heartbeat. It is used only to estimate the number of active app sessions, is not linked to an account, and is not a stable device ID.

Analytics is stored in QuaptureIQ server telemetry storage and automatically deleted after 90 days. It is available only through an owner-authenticated aggregate reporting API. The public website contains dashboard code only; it does not contain private metrics or credentials.

05

Guest access

You may use supported guest features without creating an account. Account-only features require authentication and may be associated with the authenticated user ID and account email.

06

Your deletion request

You may request deletion of your QuaptureIQ account and associated data by emailing quaptureiq.reviewer@gmail.com. Please include the email address used for your QuaptureIQ account; we may verify account ownership before processing the request.

See the public deletion instructions: https://fredrock007.github.io/quaptureiq-site/delete-account.html
