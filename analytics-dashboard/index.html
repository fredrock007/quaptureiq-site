What this dashboard currently monitors

This is the current collection status, so unavailable measurements are not mistaken for zero or healthy readings.

API-backed · five-minute windowAPI requests

p50/p95/p99 latency, request rate, HTTP errors, and requests in progress. The bounded in-memory history resets when the API restarts.

API fields · container scopeAPI container

Container CPU, memory, network throughput, and the filesystem visible to the container.

Short-lived markersApp activity

Timestamped product events and a short-lived active-session count are reported when available. Session markers expire after two minutes and are not unique-user totals.

Report status unavailableSupabase metrics

The API reports whether its server-side Supabase Metrics API feed is configured and available. Connection counts and metrics-request latency appear when supplied; this is not database query latency.

Report status unavailableHost resources and disk I/O

Host-wide CPU and RAM are not available. Disk read/write rates appear only when the API provides usable storage_io samples; container readings do not replace host readings.

Policy gapSampling and retention

Successful-request sampling is not enabled. Telemetry SQLite currently defaults to 90-day retention; 48-hour raw retention and seven-day hourly rollups are not configured.
