Alert thresholds

Threshold colors apply only to connected measurements. A missing feed is shown as unavailable and keeps the overall status at “Monitoring incomplete.” Yellow: p95 ≥ 1 s, HTTP 5xx > 1%, CPU ≥ 70%, memory ≥ 75%, filesystem ≥ 80%, or analytics queue ≥ 75%. Red: p95 ≥ 3 s, HTTP 5xx > 5%, CPU ≥ 85%, memory ≥ 90%, filesystem ≥ 90%, or queue ≥ 90%. Error thresholds require at least 10 requests.
